<h2 id="english">🇬🇧 English</h2>

**My Japanese Vocab** is a Chrome extension designed for Japanese learners. It allows you to seamlessly save vocabulary while browsing the web, automatically fetching readings, definitions, and JLPT levels to help you learn words in context.

### ✨ Features
* **Highlight & Save**: Select any Japanese word on a webpage and save it instantly using a keyboard shortcut.
* **Smart Auto-Fetch**: Automatically retrieves Hiragana/Katakana, English meanings, and JLPT levels via the Jisho API.
* **Contextual Learning**: Saves the sentence where you found the word, providing real-world context.
* **Clean Dashboard**: A minimalist, dark-mode supported UI with color-coded JLPT tags.
* **Mastery Tracking**: Move words you've learned to a separate "Mastered" list.
* **Manual Entry**: Easily add custom words using the dedicated add button.

### 📥 Installation (Developer Mode)
Since this extension is not yet published on the Chrome Web Store, you can install it locally:
1. Download this repository as a ZIP file and extract it, or run `git clone <repository-url>`.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Toggle on **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extracted project folder.
5. Pin the extension to your browser toolbar!

### 💡 Usage
1. **Save a word**: Highlight a Japanese word on any webpage and press `Ctrl + J` (Windows) or `Cmd + J` (Mac).
2. **Review your vocab**: Click the extension icon in the toolbar to open your Vocabulary Dashboard.
3. **Edit / Master**: Click on any card in the dashboard to edit the definition, update the example sentence, or mark it as "Mastered".

<h2 id="简体中文">🇨🇳 简体中文</h2>

**我的日语单词本 (マイ単語帳)** 是一款专为日语学习者设计的 Chrome 浏览器扩展。让你在浏览网页时能够无缝保存生词，自动获取假名、释义和 JLPT 等级，在真实的语境中高效背词。

### ✨ 核心功能
* **快捷划词**: 在网页上选中任意日语单词，使用快捷键一键保存。
* **智能解析**: 接入 Jisho API，自动抓取单词的读音、英文释义及 JLPT 等级（支持专属颜色标签）。
* **语境记忆**: 自动提取并保存包含该单词的网页例句，告别死记硬背。
* **清爽面板**: 支持暗黑模式的极简数据看板，卡片式管理你的生词。
* **学习进度**: 支持将已记住的单词移至“已掌握 (Mastered)”列表。
* **手动添加**: 点击紫色按钮，随时手动录入自定义单词。

### 📥 安装方法 (开发者模式)
由于扩展暂未上架 Chrome 商店，请通过以下步骤本地安装：
1. 下载此项目的 ZIP 压缩包并解压，或者使用 `git clone <仓库地址>`。
2. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车。
3. 打开页面右上角的 **“开发者模式” (Developer mode)** 开关。
4. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**，选择刚刚解压的文件夹。
5. 在浏览器右上角的拼图图标里找到它，并固定 (Pin) 到工具栏。

### 💡 使用指南
1. **保存单词**: 在任意网页选中一个日语生词，按下快捷键 `Ctrl + J` (Windows) 或 `Cmd + J` (Mac)。
2. **复习单词**: 点击工具栏上的扩展图标，打开单词本仪表盘 (Dashboard)。
3. **编辑/归档**: 点击仪表盘里的任意单词卡片，可以修改释义、例句，或将其标记为“已掌握”。

<h2 id="日本語">🇯🇵 日本語</h2>

**マイ単語帳** は、日本語学習者のための Chrome 拡張機能です。ウェブブラウジング中に見つけた知らない単語をスムーズに保存し、読み方、意味、JLPT レベルを自動取得して、文脈の中で効率よく語彙を増やすことができます。

### ✨ 主な機能
* **ハイライト＆保存**: ウェブページ上の単語を選択し、ショートカットキーで瞬時に保存。
* **自動データ取得**: Jisho API と連携し、ふりがな、意味、JLPT レベルを自動的に補完。
* **文脈で覚える**: 単語を見つけたウェブページの例文も一緒に保存。
* **クリーンな UI**: ダークモード対応、JLPT レベルごとに色分けされた見やすいダッシュボード。
* **学習進捗管理**: 覚えた単語は「マスター済み (Mastered)」リストへ移動可能。
* **手動追加**: 追加ボタンから、自分だけのカスタム単語をいつでも登録できます。

### 📥 インストール方法（デベロッパーモード）
現在 Chrome ウェブストアには公開されていないため、ローカルからインストールしてください：
1. このリポジトリを ZIP としてダウンロードして解凍するか、`git clone <repository-url>` を実行します。
2. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して移動します。
3. 右上の **デベロッパーモード (Developer mode)** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む (Load unpacked)** をクリックし、プロジェクトのフォルダを選択します。
5. ツールバーに拡張機能をピン留めして完了です！

### 💡 使い方
1. **単語を保存**: ウェブページ上の単語を選択し、`Ctrl + J` (Windows) または `Cmd + J` (Mac) を押します。
2. **単語を復習**: ツールバーのアイコンをクリックしてダッシュボードを開きます。
3. **編集・管理**: 単語カードをクリックすると、意味や例文の編集、または「マスター済み」への変更が可能です。
